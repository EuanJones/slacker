# 又活過一天存錢筒 🧈💰

`v0.8.1` · 私人測試版｜[更新紀錄](CHANGELOG.md)

> Take each day as it comes｜打工人的每日小確幸存錢筒

每撐過一天，就按一下按鈕「恭喜自己！又活過一天！」，幫自己記上一天的薪水。
一隻頂著烏雲、黑眼圈、手拿續命咖啡的上班族豆腐，會陪你一起苟活。

👉 **線上使用：** https://euanjones.github.io/slacker/

---

## 功能

- **設定金額**：建議填月薪，每天加「月薪 ÷ 當月天數（28～31 天）」，一整個月加總剛好等於月薪；日薪制也可以直接填固定日薪
- **從 2026/11/9 起算**：第一次設定時，會把起算日到昨天的天數自動補上，並跳出「偷偷告訴你～」小彈窗
- **一天只能按一次**：當天的份要傍晚 6 點後才能領，按過後顯示下次可按的倒數
- **漏按自動補領**：忘了按也沒關係，6 點前可以先補領到昨天，6 點後連今天一起領
- **週末照領**：正職月薪放假也算錢，週末按會觸發專屬台詞
- **換算拉霸** 🎲：把累積金額換算成珍奶、雞排、課金抽一單、台北房子的地磚…等 50 種以上項目
- **6 組配色 × 亮色／深色**：右下角調色盤隨時切換，也可以跟隨系統
- **背景動畫**：陰雨綿綿、暴風雨（偶爾打雷）、浮世繪大浪、陽光微風，顏色會跟著配色走
- **第 10 天達成彩蛋**：金光放射＋法被豆腐人遊行跳舞的祭典 popup，笑著哭到你自己關掉為止
- **Reset 要確認三次**：一次比一次慘，最後豆腐會直接靈魂出竅

## 資料與隱私

所有資料只存在**你這台裝置的瀏覽器（localStorage）**，不會上傳到任何地方。

- 換手機、換瀏覽器、或清除瀏覽資料，紀錄就會不見
- 不同裝置之間不會同步

## 自己架一份

整個工具就是一個 `index.html`，沒有任何建置流程。

1. Fork 或下載這個 repo
2. 想改起算日：打開 `index.html`，搜尋 `START`，修改 `new Date(2026, 10, 9)`（月份從 0 開始，10 代表 11 月）
3. 想改每天重置時間：搜尋 `RESET_HOUR`
4. 開啟 GitHub Pages（Settings → Pages → Branch: `main` / root）就能上線
